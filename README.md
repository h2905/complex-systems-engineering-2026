# 线控底盘平台课程作业

本目录包含四次独立作业和一份完整汇报，均使用同一系统边界与术语。

## 页面入口

- `index.html`：四次作业与完整汇报的统一入口
- `assignments/wire-control-chassis/index.html`：作业 01，系统层级与边界
- `assignments/concept-definition/index.html`：作业 02，BRS 与 StRS
- `assignments/system-safety-architecture/index.html`：作业 03，SyRS、架构与 STPA
- `assignments/scenario-design/index.html`：作业 04，场景分层、设计条件与风险
- `report/index.html`：26 页完整汇报
- `完整汇报.pdf`：已导出的 16:9 汇报 PDF

## 使用方式

直接用浏览器打开 `index.html`。完整汇报支持：

- 方向键、Page Up / Page Down 翻页
- 鼠标滚轮翻页
- Home / End 跳到第一页或最后一页
- 页面右下角“打印”按钮或浏览器打印功能导出 PDF

## 提交到 GitHub 前的检查

1. 在完整汇报第 29 页填写四位组员的真实姓名和实际分工。
2. 核对作业 04 中的道路宽度、坡度、转弯半径、速度等初始条件是否与小组约定一致。
3. 如老师在课堂上给出了新的参数或提交目录要求，只需修改对应页面，不需要调整样式。
4. 用浏览器实际打开 `index.html` 和 `report/index.html`，确认相对路径和页面跳转正常。

## 说明

报告中的时间、速度、转角、减速度和风险等级均为课程阶段初始基线，用于建立可讨论、可验证的设计条件，不等同于量产参数、法规认证或正式安全结论。
